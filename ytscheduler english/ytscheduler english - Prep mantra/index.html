Setup Guide (no coding or Python needed)

Do Part 1 — YouTube (~20 min) first. Do Part 2 — Instagram + Facebook later, whenever you want.

PART 1 — YouTube

Step A — Put the app on Cloudflare

  1. Log in at dash.cloudflare.com → Workers & Pages → Create → Pages tab → Upload assets (drag & drop).
  2. Give the project a name, e.g. shorts-scheduler.
  3. Make a folder that contains only this index.html, drop that folder in → Deploy.
  4. You will get a URL like https://shorts-scheduler.pages.dev. Copy it.
  5. To update the app later: open the project → Create deployment → drop the folder with the new index.html → Deploy.

Step B — Google Cloud project

  1. Go to console.cloud.google.com → project dropdown at the top → New Project → name: Shorts Scheduler → Create.
  2. APIs & Services → Library → search "YouTube Data API v3" → Enable.

Step C — OAuth consent screen

  1. Google Auth Platform (or APIs & Services → OAuth consent screen) → Get started.
  2. App name: Shorts Scheduler, support email: your Gmail. Audience: External. Contact email: your Gmail → agree → Create.
  3. Audience → Test users → Add users → add the same Gmail that owns your YouTube channel → Save. (If you skip this, login will say "access blocked".)
  4. Data Access → Add or remove scopes → tick .../auth/youtube.upload and .../auth/youtube.readonly → Update → Save.

Step D — Create the Client ID

  1. Clients → Create client (or Credentials → Create Credentials → OAuth client ID) → Application type: Web application.
  2. Under Authorized JavaScript origins → Add URI → your Cloudflare URL, e.g. https://shorts-scheduler.pages.dev (no / at the end).
  3. Leave Redirect URIs empty. Click Create → copy the Client ID (it ends with .apps.googleusercontent.com).
  4. In this app open Settings → paste the Client ID → Save. (A newly added origin can take 5–10 minutes to start working.)

Step E — Connect & upload

  1. Click YouTube Connect (top right) → choose your Gmail.
  2. If you see "Google hasn't verified this app": click Advanced → Go to Shorts Scheduler (unsafe) → tick all permissions → Continue. It is your own app, so this is safe.
  3. Your channel name appears at the top → setup done.
  4. Select videos → paste the text → Auto Match & Fill → Set times (⏱) → check everything → Upload.
  5. Keep the tab open only while uploading. After "✓ Uploaded" you can close the browser — YouTube publishes each video at its time.

⚠️ Important: Google audit

  • Videos uploaded from a new (unverified) Google project are locked to Private and will not go public automatically at the scheduled time. Until the audit is approved, make them Public/Scheduled yourself in YouTube Studio.
  • To remove the lock, fill Google's "YouTube API Services – Audit and Quota Extension Form". It asks for your app URL, a Privacy Policy and Terms page (you can create these pages on your WordPress site). Approval can take a few weeks.
  • Quota: about 100 uploads per day (Google's default limit). Your YouTube channel also has its own separate daily upload limit.

PART 2 — Instagram + Facebook (~30–40 minutes)

The Instagram API cannot schedule posts by itself, so a small Cloudflare Worker stores the videos and posts them at the right time. You need the worker.js file that came with this app.

✅ Before you start — have these ready

  • A Facebook Page where you are an admin.
  • An Instagram account of type Business, linked to that Page (Step A).
  • Your Cloudflare account (the same one that hosts this app).
  • The worker.js file — open it in a text editor (on Ubuntu: "Text Editor") so you can copy its code.
  • A password you choose (e.g. MyShorts@2026) — this becomes your APP_PASSWORD.

Step A — Make Instagram a Business account and link it to your Page

  1. In the Instagram app → Profile → ☰ menu → Settings and activity → Account type and tools → Switch to professional account.
  2. Pick a category (e.g. "Education" or "Digital creator") → choose Business (not Creator).
  3. Link it: Instagram → Settings → Accounts Center → Accounts → Add accounts → add your Facebook account. Then Instagram profile → Edit profile → Page → select your Facebook Page.
  4. Check: Facebook Page → Settings → Linked accounts should show Instagram as "Connected".

Step B — Create storage on Cloudflare

  1. Cloudflare dashboard → left menu R2 Object Storage → Enable / Get started. If it asks for a card, add one — there is no charge up to 10 GB.
  2. Create bucket → name shorts-videos → Location: Automatic → Create.
  3. Left menu Storage & Databases → Workers KV → Create instance → name shorts-queue → Create.

Step C — Create the Worker

  1. Workers & Pages → Create → Worker (or "Start with Hello World") → name shorts-api → Deploy.
  2. Click Edit code → select all the code on the left (Ctrl+A) and delete it → paste the full code from your worker.js file → click Deploy (top right).
  3. Go back to the Worker's page → Settings → Bindings → Add binding:
    • R2 bucket → Variable name: MEDIA (exactly this, in capitals) → bucket: shorts-videos → Add.
    • KV namespace → Variable name: DB → namespace: shorts-queue → Add.
  4. Settings → Variables and Secrets → Add → Type: Secret → Name: APP_PASSWORD → Value: your chosen password → Save/Deploy. (You will add META_APP_ID and META_APP_SECRET the same way after Step D.)
  5. Settings → Trigger events / Triggers → Add → Cron Triggers → choose "Every 5 minutes" (or type */5 * * * *) → Add.
  6. Copy the Worker URL (shown on its overview page, e.g. https://shorts-api.yourname.workers.dev). Open it in a browser — you should see "Shorts Scheduler worker chal raha hai ✓".
  7. In this app open Settings → enter the Worker URL + App Password → Save & Check → you should see "✓ Worker connected". (A yellow META warning is normal until Step D is done.)

Step D — Meta (Facebook) developer app

  1. Go to developers.facebook.com → log in with Facebook → if it's your first time, click Get Started to create a developer account (verify phone/email).
  2. My Apps → Create App → App name: Shorts Scheduler → contact email: your Gmail.
  3. When asked for a use case, choose "Manage everything on your Page" and "Manage messaging & content on Instagram" (or whichever option mentions publishing content to Instagram). If you see an "Other" option, choose Other → Business. If it asks for a Business portfolio, choose "I don't want to connect" or pick your portfolio.
  4. After the app is created: App settings → Basic → copy the App ID, then App secret → Show → copy it.
  5. In your Cloudflare Worker → Settings → Variables and Secrets add two more Secrets: META_APP_ID = App ID, META_APP_SECRET = App secret → Save/Deploy.
  6. Leave the app in Development mode. You are the app's admin, so no App Review is needed to post to your own Page/Instagram.

Step E — Create a token and connect

  1. Open Graph API Explorer → on the right, under Meta App, select Shorts Scheduler → under User or Page choose "User Token".
  2. Under Permissions add all of these:
    pages_show_list pages_read_engagement pages_manage_posts business_management instagram_basic instagram_content_publish
  3. Click Generate Access Token → in the popup choose "Opt in to all current and future Pages" or tick your Page, and tick your Instagram account too → Continue / Save.
  4. A long token (starting with EAA…) appears in the Access Token box → copy it.
  5. In this app: Settings → Facebook Page + Instagram connect → paste → Connect. If you have more than one Page, it will ask for a number.
  6. You should see: ✓ Connected · Page: your Page · Instagram: @your_username. Setup complete! 🎉

Step F — First test

  1. App tab → add one short video → tick only Instagram Reels → Mode: Abhi Public (publish now) → Upload.
  2. Open the Insta/FB Queue tab → click ▶ Abhi check kariye (check now). Within 1–2 minutes it should show "✓ Posted · dekhiye" (view).
  3. Once that works, test with Facebook ticked, then start your scheduled bulk uploads.
  4. Videos are stored on the Worker until posted, then deleted automatically. Each video must be under 100 MB (Cloudflare free limit). Posts may go out 5–10 minutes after the set time, because the Worker checks every 5 minutes.
  5. Instagram caption = Title + Description + hashtags (max 30 hashtags; #shorts is not added on Instagram).

🔧 Troubleshooting (common errors)

  • "Worker tak nahi pahunch paaye" (can't reach Worker) → the Worker URL is wrong or has extra text at the end. Use only https://….workers.dev.
  • "Galat App Password" (wrong password) → the password in the app and the Worker's APP_PASSWORD secret must match exactly (including capitals).
  • "R2 binding MEDIA ya KV binding DB nahi mili" (bindings missing) → redo Step C-3; check the names are spelled in capitals.
  • "Koi Facebook Page nahi mila" (no Page found) → you didn't tick your Page when creating the token, or pages_show_list was missing. Redo Step E.
  • "Instagram Business account juda nahi" (Instagram not linked) → redo Step A; Instagram must be Business type and linked to the same Page. Then create a new token and Connect again.
  • "Meta token expire/galat (code 190)" (token expired) → redo Step E (new token → Connect). With META_APP_ID/SECRET set on the Worker, the token lasts much longer.
  • "Instagram ne video reject kiya" (video rejected) → the video must be MP4 (H.264 video + AAC audio), 9:16, longer than 3 seconds and under 100 MB.
  • Post didn't go out on time → check the Worker's Cron Trigger (Step C-5). Meanwhile you can click "Abhi check kariye" in the Queue tab.
  • Code 9 / rate limit → Instagram's daily posting limit; the Worker will automatically retry a little later.

Text paste format

Video: how-to-kill-a-mat
Title: Mat ko kaise hataye? 😮
Description: Is video me jaaniye ek aasaan trick.
A second line is fine too.
#shorts #hacks #hindi
---
Video: atm-cash-kaise-nikalti-hai
Title: ATM se cash kaise nikalta hai?
Description: ...
Tags: atm, bank, cash
  • If a block has a Video: line (the file name), the match is exact. Without it, the app matches the words of the Title with the file name.
  • --- separates one video's block from the next.
  • Words starting with # become both hashtags and tags. A Tags: line takes comma-separated tags.
  • If there are no labels at all: first line = Title, the rest = Description.
